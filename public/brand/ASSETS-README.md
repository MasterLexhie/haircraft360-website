# Haircraft360 web logo assets

## Files

Each colorway has a complete logo (`*-full`) and an icon-only crop (`*-icon`) in PNG, WebP, and SVG containers. The variants follow the supplied references: black/white, pink/black, and orange/white. PNG and WebP files use transparent backgrounds where the source image allows it.

## Important format note

The supplied artwork is raster imagery (JPEG/PNG), not original vector artwork. The SVG files are valid SVG wrappers containing embedded transparent PNG images; they are useful for sites that accept SVG, but the artwork itself is not composed of editable vector paths and will not gain detail when enlarged. The PNG/WebP are the practical web formats. A clean, infinitely scalable vector would require the original design source or a manual vector redraw.

The supplied pink logo uses a black circular badge; that black badge is retained as part of the mark.
